## Introduction

Game Explore is a web platform that allows users to discover and explore games based on various genres and gaming platforms. The goal is to provide a comprehensive and user-friendly experience for gamers to find new and exciting games to play.

## Features

- Browse games by genre (e.g., Action, Adventure, RPG, etc.)
- Filter games by gaming platform (e.g., PC, PlayStation, Xbox, etc.)
- View detailed information about each game, including descriptions, release dates, and more
- User reviews and ratings for each game

## Technologies Used

- **Front-end:** HTML, CSS, TypeScript, React
- **Back-end:** Node.js,
- **Database:** Moby Games
- **APIs:** Game data retrieved from external game databases (e.g., RAWG API)

## Installation

To run the project locally, please follow these steps:

1. Clone the repository:
    ```bash
    git clone https://github.com/SegunDada/game-explore.git
    ```
2. Navigate to the project directory:
    ```bash
    cd game-explore
    ```
3. Install the required dependencies for both the front-end and back-end:
    ```bash
    cd client
    npm install
    cd ../server
    npm install
    ```

## Usage

To start the development server:

1. Navigate to the server directory and start the back-end server:
    ```bash
    cd server
    npm start
    ```
2. In a separate terminal, navigate to the client directory and start the front-end development server:
    ```bash
    cd client
    npm start
    ```

Open your browser and go to `http://localhost:3000` to explore the Game Explore platform.
